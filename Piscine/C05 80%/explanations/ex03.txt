Ex03 – ft_recursive_power

Goal (in simple words):
Compute nb^power using recursion.

What you are expected to do:
- If power < 0, return 0.
- If power == 0, return 1.
- Otherwise return nb * power(nb, power - 1).

How to write it (step-by-step):
1) Handle power < 0.
2) Base case: power == 0 returns 1.
3) Recursive case multiplies by nb and reduces power.

Why it works:
- Each call reduces the exponent until it reaches 0.
