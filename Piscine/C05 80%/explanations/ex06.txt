Ex06 – ft_is_prime

Goal (in simple words):
Return 1 if nb is prime, otherwise 0.

What you are expected to do:
- 0 and 1 are not prime.
- 2 is prime.
- Even numbers > 2 are not prime.
- Test odd divisors up to sqrt(nb).

How to write it (step-by-step):
1) Handle nb <= 1.
2) Handle nb == 2.
3) If nb is even, return 0.
4) Test odd i from 3 while i * i <= nb.
5) If any divisor found, return 0. Else return 1.

Why it works:
- A non-prime has a divisor <= sqrt(nb).
