Ex00 – ft_iterative_factorial

Goal (in simple words):
Compute the factorial of nb using a loop.

What you are expected to do:
- If nb is negative, return 0.
- Otherwise compute: nb! = nb * (nb-1) * ... * 1.

How to write it (step-by-step):
1) If nb < 0, return 0.
2) Set result = 1.
3) While nb > 1:
   - result *= nb
   - nb--
4) Return result.

Why it works:
- Multiplying from nb down to 1 produces the factorial.

Beginner tips:
- No recursion is needed here.
- Overflow handling is not required.
