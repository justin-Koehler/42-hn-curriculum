Ex02 – ft_iterative_power

Goal (in simple words):
Compute nb^power using a loop.

What you are expected to do:
- If power < 0, return 0.
- If power == 0, return 1.
- Otherwise multiply nb by itself power times.

How to write it (step-by-step):
1) If power < 0, return 0.
2) Set result = 1.
3) While power > 0:
   - result *= nb
   - power--
4) Return result.

Why it works:
- Repeated multiplication builds the power.
