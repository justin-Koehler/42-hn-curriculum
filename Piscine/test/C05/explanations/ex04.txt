Ex04 – ft_fibonacci

Goal (in simple words):
Return the n-th Fibonacci number using recursion.

What you are expected to do:
- If index < 0, return -1.
- If index == 0, return 0.
- If index == 1, return 1.
- Otherwise return fib(index - 1) + fib(index - 2).

How to write it (step-by-step):
1) Handle negative index.
2) Use base cases for 0 and 1.
3) Use recursion for all other cases.

Why it works:
- Each Fibonacci number is the sum of the two previous ones.
