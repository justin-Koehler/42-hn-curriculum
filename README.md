# 42 Common Core Portfolio

This repository contains my solutions, documentation, and conceptual breakdowns for the 42 Heilbronn Common Core curriculum. 

## Philosophy

The 42 network thrives on peer-to-peer learning. This repository is built as a learning resource to explain logic and edge cases. **Learn, do not copy.** Code duplication is strictly penalized by the system and prevents true learning.

---

## Directory Structure

### Guides
Conceptual deep dives into fundamental computer science topics:
*   [Pointers](Guides/pointer.md)
*   [Heap vs Stack](Guides/heap.md)

### Circle 01
*   **Libft**: Reimplementation of standard C library functions. Focuses on low-level memory handling and pointer manipulation.

### Circle 02
*   **ft_printf**: Recreating printf to understand variadic functions and formatting logic.
*   **get_next_line**: A function to read a file descriptor line by line. Focuses on static variables and buffer management.

### Circle 03+
*   *Upcoming projects (pipex, push_swap, minishell) will be documented as I progress.*

---

## Technical Standards

All source code inside this repository strictly complies with the following guidelines:
*   **The Norminette**: Strict 42 code formatting standard.
*   **Memory Integrity**: Zero memory leaks and zero dangling pointers.
*   **Defensive Coding**: Full protection against NULL pointers and critical edge cases.
